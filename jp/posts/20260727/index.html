git配置SSH key并连接Github 链接到标题

生成对应github账号邮箱地址的ssh key ssh-keygen -t rsa -C <account@email.com> 将’.ssh/id_rsa/id_rsa.pub’文件里的密钥添加到github主页个人设置里的SSH and GPG keys

Windows下解决使用git远程SSH连接github仓库时端口报错 链接到标题

测试连接 ‘ssh -T git@github.com’ 报错 ‘ssh: connect to host github.com port 22: Connection refused’

在git路径下的配置文件/Git/etc/ssh/ssh_config末尾加上 ’’’ Host github.com User 568725036@qq.com Hostname ssh.github.com PreferredAuthentications publickey IdentityFile ~/.ssh/id_rsa Port 443 ’’'

Hugo Papermod 部署问题：上传 GitHub Page 后不显示CSS样式 链接到标题

git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod

开发环境: Windows 11 Theme: PaperMod

访问网站无法正常显示CSS样式，F12提示报错“Failed to find a valid digest in the ‘integrity’ attribute for resource”。

最后是在这个stackoverflow 的回答中找到解决方法。

将以下代码添加到hugo.yml文件，再次上传就正常显示了。 yml：

params: assets: disableFingerprinting: true

toml:

[params.assets] disableFingerprinting = true
